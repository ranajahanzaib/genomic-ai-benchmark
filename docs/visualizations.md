# Visualizations

The Overview and Embedding Atlas use Canvas to render a selectable projection of fixture sequence composition features. The projection is deterministic but not UMAP or a neural representation. Point selection updates the record detail and nucleotide sequence view. The theme button toggles a dark palette.

No annotation, conservation, model attribution, variant-effect, or real genome-coordinate tracks are present. The UI states that annotation tracks are unavailable rather than fabricating them.
